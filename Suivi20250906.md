## ✅ CHECKLIST détaillée (avec pistes d’avancement)

### A. Auth / Session

* [ ] **Middleware de vérif JWT commun pour toutes les functions**
  **Action :** créer `/.netlify/functions/_utils/withAuth.js` et `verifyAuth0JWT.js`
  **Piste :**

  ```js
  // withAuth.js
  import { verifyAuth0Token } from './verifyAuth0JWT'
  export const withAuth = (handler) => async (event, context) => {
    try {
      const token = (event.headers.authorization || '').replace('Bearer ', '')
      const claims = await verifyAuth0Token(token) // vérifie iss/aud/exp/alg via jwks-rsa
      event.auth = claims
      return handler(event, context)
    } catch (e) {
      return { statusCode: 401, body: 'Unauthorized' }
    }
  }
  ```

  → Remplacer l’export de chaque function par `export const handler = withAuth(async (event) => { ... })`
